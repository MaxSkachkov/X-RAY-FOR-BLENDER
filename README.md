# Skachkov Design

Портфолио Макса Скачкова — full-stack разработчика. Здесь собраны цифровые проекты, созданные с вниманием к понятному интерфейсу, работающей логике и целям бизнеса.

## Проекты

- [DEMOFIZ](https://maxskachkov.github.io/demofiz/) — интерактивный образовательный проект: физические формулы и симуляции, которые помогают учиться через наглядный эксперимент.

## О сайте

Статический сайт на HTML и CSS. Публикуется через GitHub Pages.

- Главная страница: index.html
- Стили: main.css
- Устаревшие адреса страниц городов перенаправляют на портфолио, чтобы старые ссылки не вели на вымышленное описание гида.

## Разработка

Откройте index.html в браузере. Сборка и зависимости не требуются.
