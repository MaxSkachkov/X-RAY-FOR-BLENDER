Same pose, four directions

          
  1. Keep the first four views in the same neutral, symmetrical A-pose.
  2. Use arms roughly 35–45° from the torso, relaxed hands and slightly separated feet.
  3. Only the viewing direction changes. Keep camera height, framing and scale consistent.

          

          
A-pose views describe the character's shape. Bent elbows and knees are separate checks for deformation after a rig exists. A seated pose cannot replace the core turnaround set.

          
A multi-view collage can help you review the set, but keep each required angle as a separate source image.

A viewer and preparation helper
Use Blender for modeling, rig creation and production work. This app helps you prepare and inspect.
01
No photo-to-rig automation
Reference images are shown only in your browser. There is no connected algorithm that creates a 3D character or rig from photographs.
02
GLB is an exchange format
Skinning, mesh and embedded animation clips can be inspected. Blender IK, constraints, drivers and all Rigify controls are not preserved as interactive controls here.
03
Local processing
Images and model data are read in this browser tab. User assets are not sent to a service or committed to the repository. This viewer does not export .blend files.
